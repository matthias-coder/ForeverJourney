# ForeverJourney Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Windows-Hintergrundtool, das MyCharForever-Exportdateien liest, sie kumulativ in JSON je Charakter zusammenführt, Screenshots verkleinert und alles ins Git-Repo pusht.

**Architecture:** Reine Python-Pipeline aus kleinen Modulen (Lua-Parser → Merge → Screenshots → Index → Git), orchestriert von `pipeline.py`. Ein Dateiwächter löst die Pipeline aus, ein Tray-Prozess hält alles am Leben. Jeder Schritt ist ohne Tray und ohne Git testbar.

**Tech Stack:** Python 3.14 (vorhanden), venv unter `tool/.venv`, pytest, Pillow (Bilder), watchdog (Dateiwächter), pystray (Tray), winotify (Benachrichtigungen), `tomllib` (Stdlib), Git über `subprocess`.

**Spec:** `docs/superpowers/specs/2026-11-07-forever-journey-design.md` (Abschnitte 5 und 6) und der Datenvertrag `docs/superpowers/specs/2026-11-07-data-contract.md`. Addon-Schema: `C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\MyCharForever\docs\EXPORT_SCHEMA.md`.

## Global Constraints

- Nur `MyCharForeverExportDB` lesen; `MyCharForeverDB` und `settings` nie verarbeiten oder schreiben.
- Nie ins Repo: Account-Name, lokale Pfade, `meta.profileKey`, Original-Screenshots.
- Datei erst verarbeiten, wenn sie 5 s unverändert ist und vollständig parsebar; sonst nichts überschreiben.
- Unbekannte `exportVersion` (≠ 3): Lauf für diesen Charakter abbrechen, Hinweis, nichts schreiben.
- Repo-JSON ist die Langzeit-Wahrheit: Listen aus dem Datenvertrag werden vereinigt, `state` ersetzt.
- Bilder: max. 1600 px Breite, JPEG Qualität 80, Vorschaubild 320 px, immer `.jpg`; Originale unberührt.
- Screenshots per Export-Referenz oder Session-Zeitfenster (`startTime - 60 .. endTime + 60`) zuordnen; außerhalb jeder Session ignorieren.
- Keine blockierenden Dialoge; Fehler nur als Tray-Hinweis und Logfile `tool/foreverjourney.log`.
- Commit-Message: `chronicle: <displayName> <YYYY-MM-DD>`; bei Push-Fehler lokal committen, später erneut pushen.
- Alle Tests laufen mit `cd tool && .venv/Scripts/python -m pytest -q`.
- Code und Commits auf Englisch, Nutzertexte (Tray, README) auf Deutsch.

## Review Focus

1. Lua-Datei wird gerade von WoW geschrieben (abgeschnitten, endet mitten in einer Tabelle): Parser muss einen Fehler werfen, Pipeline darf nichts schreiben. → Test in Task 1 (`test_truncated_file_raises`) und Task 6 (`test_unparsable_export_leaves_repo_untouched`).
2. Zweiter Charakter mit gleichem Vornamen, anderem Nachnamen: beide bekommen eigene IDs und Ordner. → Test in Task 2 (`test_char_id_includes_realm`).
3. Export mit 2000 Ereignissen, von denen die ältesten gegenüber dem Repo-Stand fehlen: Repo behält sie. → Test in Task 3 (`test_merge_keeps_events_dropped_by_addon`).
4. Screenshot-Datei im Export referenziert, aber auf der Platte nicht vorhanden (noch nicht gespeichert oder gelöscht): Eintrag ohne Bild, kein Absturz. → Test in Task 4 (`test_missing_file_is_skipped`).
5. Export-Datei eines Charakters verschwindet (Charakter gelöscht): Index zeigt `retired`, JSON bleibt. → Test in Task 5 (`test_status_retired_when_export_missing`).

from pathlib import Path
import pytest
from foreverjourney.luaparse import parse_saved_variables, load_export, LuaParseError

FIX = Path(__file__).parent / "fixtures" / "MyCharForever.lua"

def test_parses_scalars_and_escapes():
    t = 'X = {\n\t["a"] = 1,\n\t["b"] = -2.5,\n\t["c"] = "Hogger \\"der\\" \\n",\n\t["d"] = true,\n\t["e"] = nil,\n}\n'
    r = parse_saved_variables(t)["X"]
    assert r == {"a": 1, "b": -2.5, "c": 'Hogger "der" \n', "d": True, "e": None}

def test_array_tables_become_lists():
    r = parse_saved_variables('X = {\n\t{\n\t\t["t"] = 1,\n\t}, -- [1]\n\t{\n\t\t["t"] = 2,\n\t}, -- [2]\n\t"s", -- [3]\n}\n')["X"]
    assert r == [{"t": 1}, {"t": 2}, "s"]

def test_numeric_and_mixed_keys_stay_dict():
    r = parse_saved_variables('X = {\n\t[5] = "five",\n\t[7] = "seven",\n}\n')["X"]
    assert r == {5: "five", 7: "seven"}

def test_multiple_top_level_variables():
    r = parse_saved_variables('A = {\n}\nB = {\n\t["k"] = 1,\n}\n')
    assert set(r) == {"A", "B"} and r["B"] == {"k": 1}

def test_truncated_file_raises():
    text = FIX.read_text(encoding="utf-8")
    with pytest.raises(LuaParseError):
        parse_saved_variables(text[: len(text) // 2])

def test_load_export_fixture():
    exp = load_export(FIX)
    assert exp["exportVersion"] == 3
    assert exp["meta"]["name"] == "Thorgrim"
    assert exp["data"]["events"][1]["type"] == "LEVEL_UP"
    assert exp["data"]["journey"]["segments"][0][0] == [1791830400, 1426, 0.4, 0.5, 1]

# tool/tests/test_merge.py
import copy
from pathlib import Path
from foreverjourney.luaparse import load_export
from foreverjourney.merge import export_to_record, merge_records

FIX = Path(__file__).parent / "fixtures" / "MyCharForever.lua"

def fresh():
    return export_to_record(load_export(FIX), None)

def test_record_shape_and_privacy():
    r = fresh()
    assert r["schemaVersion"] == 1 and r["id"] == "thorgrim-eisenbart"
    assert "profileKey" not in r["meta"] and r["meta"]["clientFlavor"] == "forever"
    assert "settings" not in r["state"]
    assert r["state"]["levels"]["3"]["duration"] >= 0          # numeric keys → strings
    assert [e["type"] for e in r["lists"]["events"]] == ["LOGIN", "LEVEL_UP", "DEATH", "LOGOUT"]
    assert r["lists"]["journeySegments"][0][0] == [1791830400, 1426, 0.4, 0.5, 1]
    assert r["lists"]["journeyGhost"] == [False]
    assert r["config"] == {"status": None, "mode": "normal", "realmType": None, "realmName": None, "armoryUrl": None}

def test_merge_keeps_events_dropped_by_addon():
    old = fresh()
    new = fresh()
    new["lists"]["events"] = new["lists"]["events"][2:] + [{"time": 1793556000, "type": "LOGIN"}]
    m = merge_records(old, new)
    assert [e["time"] for e in m["lists"]["events"]] == [1791830400, 1791830651, 1791831200, 1791834000, 1793556000]

def test_merge_new_wins_on_duplicate_and_state_replaced():
    old = fresh(); new = copy.deepcopy(old)
    new["lists"]["sessions"][0]["duration"] = 999
    new["state"]["levelSnapshots"]["2"]["money"] = 1
    old["goldHistory"]["2020-01-01"] = {"first": 1}
    m = merge_records(old, new)
    assert m["lists"]["sessions"][0]["duration"] == 999 and len(m["lists"]["sessions"]) == 1
    assert m["state"]["levelSnapshots"]["2"]["money"] == 1
    assert set(m["goldHistory"]) == {"2026-10-12", "2020-01-01"}

def test_merge_keeps_existing_shots_and_rejects_other_id():
    old = fresh(); old["shots"] = {"a.jpg": {"file": "x"}}
    assert merge_records(old, fresh())["shots"] == {"a.jpg": {"file": "x"}}
    other = fresh(); other["id"] = "someone-else"
    import pytest
    with pytest.raises(ValueError):
        merge_records(old, other)

def test_merge_without_existing_returns_fresh():
    r = fresh()
    assert merge_records(None, r)["lists"] == r["lists"]

### Task 4: Screenshots auswählen und verkleinern

**Files:**
- Create: `tool/foreverjourney/shots.py`
- Test: `tool/tests/test_shots.py`

**Interfaces:**
- Consumes: Charakter-JSON (`lists.screenshots`, `lists.sessions`, `shots`) aus Task 3; `Config` aus Task 2.
- Produces: `read_exclude(path: Path) -> set[str]` (Datei darf fehlen → leere Menge; `#`-Zeilen und Leerzeilen ignoriert; Namen getrimmt).
- Produces: `screenshot_time(name: str) -> int | None` – parst `WoWScrnShot_MMDDYY_HHMMSS.<ext>` als **lokale** Zeit des PCs zu Unix-Sekunden; sonst `None`.
- Produces: `select_candidates(record: dict, screenshot_dir: Path, exclude: set[str]) -> list[Candidate]` mit `@dataclass Candidate(name: str, path: Path, source: str, meta: dict)`; `source="export"` für Einträge aus `lists.screenshots` (Datei muss existieren, sonst übersprungen), `source="session"` für Dateien im Ordner, deren Zeit in `[startTime-60, endTime+60]` einer Session liegt und die nicht schon per Export erfasst sind. Bereits in `record["shots"]` vorhandene Namen und `exclude` werden übersprungen.
- Produces: `process_image(src: Path, dest_dir: Path, name: str, max_width: int, thumb_width: int, quality: int) -> tuple[Path, Path, int, int]` – schreibt `dest_dir/<stem>.jpg` und `dest_dir/t_<stem>.jpg`, gibt (file, thumb, width, height) des großen Bildes zurück.
- Produces: `apply_exclusions(record: dict, shots_dir: Path, exclude: set[str]) -> list[str]` – entfernt ausgeschlossene Einträge aus `record["shots"]` und löscht deren Dateien; gibt entfernte Namen zurück.
- Produces: `update_shots(record: dict, cfg: Config, repo_dir: Path, exclude: set[str]) -> list[str]` – führt Auswahl, Verarbeitung und Eintrag in `record["shots"]` (Felder laut Datenvertrag, Pfade relativ zum Repo mit `/`) aus; gibt neu hinzugefügte Namen zurück.

# tool/tests/test_shots.py
import time
from pathlib import Path
from PIL import Image
from foreverjourney.shots import read_exclude, screenshot_time, select_candidates, process_image, apply_exclusions, update_shots
from foreverjourney.config import load_config
from foreverjourney.luaparse import load_export
from foreverjourney.merge import export_to_record

FIX = Path(__file__).parent / "fixtures" / "MyCharForever.lua"

def make_img(p, w=2560, h=1440):
    Image.new("RGB", (w, h), (30, 90, 40)).save(p)

def test_read_exclude_handles_missing_and_comments(tmp_path):
    assert read_exclude(tmp_path / "none.txt") == set()
    (tmp_path / "e.txt").write_text("# comment\n a.jpg \n\nb.jpg\n", encoding="utf-8")
    assert read_exclude(tmp_path / "e.txt") == {"a.jpg", "b.jpg"}

def test_screenshot_time_parses_local_time():
    t = screenshot_time("WoWScrnShot_101226_204411.jpg")
    assert time.localtime(t)[:6] == (2026, 10, 12, 20, 44, 11)
    assert screenshot_time("foo.jpg") is None

def test_select_candidates_export_session_and_missing(tmp_path):
    rec = export_to_record(load_export(FIX), None)
    rec["shots"] = {}
    sd = tmp_path / "Screenshots"; sd.mkdir()
    make_img(sd / "WoWScrnShot_101226_204411.jpg")           # referenced in export → export
    in_session = time.strftime("WoWScrnShot_%m%d%y_%H%M%S.jpg", time.localtime(1791831000))
    make_img(sd / in_session)                                   # inside session → session
